# ◉대통령령 제34952호

아동복지법 시행령 일부개정령 아동복지법 시행령 일부를 다음과 같이 개정한다. 별표 14 제1호 중 지역아동센터란을 다음과 같이 한다.

지역 아동 센터 | 아동 30명 이상|1명| | | | |1명 (아동 50명 이상인 경우만 해당함)| |3명 (아동50명 초과 시 1명 추가)| | | | | | |
------------------------
지역 아동 센터 | 아동 30명 미만 25명 이상|1명| | | | | | |2명| | | | | | |
지역 아동 센터 | 아동 25명 미만 10명 이상|1명| | | | | | |1명| | | | | | |

## 부칙

부 칙
이 영은 2025년 1월 1일부터 시행한다.

## 개정이유 및 주요내용

◇개정이유 및 주요내용
지역아동센터를 이용하는 아동에 대한 돌봄 서비스를 강화하기 위하여 지역아동센터에 배치해야 하 는 생활복지사의 수를 아동 정원이 30명 이상인 지역아동센터에 대해서는 2명에서 3명으로, 아동 정 원이 25명 이상 30명 미만인 지역아동센터에 대해서는 1명에서 2명으로 각각 확대하려는 것임.
