# 제19743호 가 보 2020. 5. 4.(월요일)

◉대위지방국토관리청고시제2020-171호하천윐용 허가

「하천법」 제33조제7항과 같은 법 시행령 제38조의 규정에 따라 다음과 같이 하천윐용 허가사항을 고시합니다.

2020년 5월 4일 대위지방국토관리청장

1. 하천명칭: 미호천
2. 허가번호: 제2020-37호
3. 피허가자

가. 성명: 세종시 연동면장
나. 주소: 세종특별자치시 연동면 내장욱진로 7

4. 윐용개요

가. 목면적: 공작물 설치
나. 개요: 마을 진입로 확장 (L=53m, B=1.0~1.5m)

5. 윐용위치 및 면면적

가. 위치: 세종특별자치시 연동면 예양리 650-1번지 외 1필지
나. 면면적: 68㎡

6. 윐용기간: 2020. 4. 28. ~ 2025. 4. 27.

◉대위지방국토관리청고시제2020-172호하천윐용 허가

「하천법」 제33조제7항과 같은 법 시행령 제38조의 규정에 따라 다음과 같이 하천윐용 허가사항을 고시합니다.

2020년 5월 4일 대위지방국토관리청장

1. 하천명칭: 금강
2. 허가번호: 제2020-38호
3. 피허가자

가. 성명: 공주시장(건설과장)
나. 주소: 충청남도 공주시 밉황로 1

4. 윐용개요

가. 목면적: 공작물 설치
나. 개요: 계류장 진출입로

5. 윐용위치 및 면면적

가. 위치: 충청남도 공주시 금성동 164-1, 69-1번지
나. 면면적: 725㎡

6. 윐용기간: 2020. 4. 28. ~ 2025. 4. 27.
