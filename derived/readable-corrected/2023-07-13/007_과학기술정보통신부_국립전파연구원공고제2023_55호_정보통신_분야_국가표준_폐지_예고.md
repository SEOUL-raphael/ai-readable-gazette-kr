순번 | 표준번호 | 표준명

4|KS X ISO/IEC 18028-2|정보 기술 ― 정보 보안 - IT네트워크보안 ― 제2부 : 네트워크 보안 구조
5|KS X ISO/IEC 18028-1|정보 기술 ― 보안 기술 - IT네크워크보안 ― 제1부 : 네트워크 보안 관리

2. 폐지 사유

① KS X ISO/IEC 8613-12 : 부합화 국제표준 폐지(`21.11월)
② KS X ISO/IEC 11802-2 : 부합화 국제표준 폐지(`23.6월)
③ KS X ISO/IEC 9594-10 : 부합화 국제표준 폐지(`13.3월)
④ KS X ISO/IEC 18028-2 : 부합화 국제표준 폐지(`09.12월)
⑤ KS X ISO/IEC 18028-1 : 부합화 국제표준 폐지(`12.7월)

3. 주요 내용

① (KS X ISO/IEC 8613-12) 정보 기술 ― 개방형문서구조(ODA)와 교환서식: 문서 프래그먼트의 식별

- 기억 매체의 교환 또는 데이터 통신에 의한 문서의 작성, 교환을 위한 서식을 제시

② (KS X ISO/IEC 11802-2) 정보 기술 ― 전기통신과 시스템간의 정보 교환 ― 근거리망과 광역망

― 제2부: 표준 그룹 MAC 주소

- LAN MAC 주소의 2진과 16진 표현법, MAC 주소 블록 관련 설명 및 규정 제시

③ (KS X ISO/IEC 9594-10) 정보 기술 ― 개방형 시스템간 상호접속 ― 디렉토리: 디렉토리 운영을 위한 시스템 관리의 사용

- OSI 시스템 관리 서비스와 디렉토리 서비스와 구별하기 위한 요구사항 설명 및 모델 제시

④ (KS X ISO/IEC 18028-2) 정보 기술 ― 정보 보안 - IT네트워크보안 ― 제2부: 네트워크 보안 구조

- 단 대 단 네트워크 보안을 제공하기 위한 네트워크 보안 구조를 정의

⑤ (KS X ISO/IEC 18028-1) 정보 기술 ― 보안 기술 - IT네크워크보안 ― 제1부: 네트워크 보안 관리

- 정보 시스템 네트워크 자체 접속 또는 네트워크에 원격 사용자가 접속함에 있어 보안 측면에 대한 것을 포함한 네트워크 통신에 관한 방침을 제공
