# 제19846호 가 보 2020. 9. 28.(월요일)

◉부산지방국토관리청공고제2020-177호도로사용(임시개통) 개시

도로법 제39조의 규정에 의하여 도로의 임시 사용개시 구간을 다음과 같이 공고합니다. 2020년 9월 28일 부산지방국토관리청장

1. 도로의 종류 : 일반국도(자동차위용도로)
2. 노선번호 및 노선명 : 국도7호선(부산-온성)
3. 사용개시구간 : 연장 7.7km(신설 4차로) 경상남도 양산시 용당동 ~ 울산광역시 울주군 웅찌면 대복리

- 임시사용 기간 : 2020. 09. 28. 14시 ~ 2020. 10. 05. 14시(8일간)

4. 개 시 일 시 : 2020년 09월 28일
5. 도면의 열람기간 및 열람장소

1) 공람기간 : 공고일로부터 2020년 10월 5일까지
2) 열람장소 : 부산지방국토관리청 도로계획과(전화번호 : 051-660-1107)

웅상-무거1 국도건설공사 프장사무실(전화번호 : 052-716-0077)
웅상-무거2 국도건설공사 프장사무실(전화번호 : 052-224-7001)

6. 비 고 : 부산지방국토관리청에서 시행접인 “웅상-무거1,2 국도건설공사”와 가련하여 추석연 휴기간 교통수요에 원활히 대처하기 위해 경남 양산시 용당동~울산광역시 울주군 웅찌면 대복리 간을 임시개통함.

※ 첨부서류 : 위 치 도<게재생략>
