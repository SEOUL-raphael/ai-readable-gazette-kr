# 제19937호 가 보 2021. 2. 9.(화요일)

◉여수지방해양수산청고시제2021-12호

비관리청 항만개발사업 시행변경허가

「항만법」제9조제9항의 규정에 의하여 다음과 같이 비관리청 항만개발사업 시행변경허가 하씀기에 이를 고시합니다.

2021년 2월 9일 여수지방해양수산청장

1. 항만명 : 갑양항
2. 공사의 명칭 : 낙포가공선부두 내 해양환경공단 방제대응센터 신축공사
3. 공사 장소 : 여수시 낙포동 355-38(낙포가공선부두 내)
4. 공사개요 : 방제대응센터 1동(845.33 m2), 부대공 1식
5. 공사기간(변경)

- (변경 위) 착공일로부터 210일 (변경 후) 착공일로부터 270일

6. 공사에 필요한 총사업비(변경)

- (변경 위) 금1,664,346,841원(비귀속) (변경 후) 금1,439,013,636원(비귀속)

7. 공사시행자

- 성명 : 해양환경공단 이사장 박승기
- 주소 : 서울시 송파구 송파대로 28길 28.

◉대산지방해양수산청고시제2021-8호
