# 징계위원회출석통지(국립농산물품질관리원 보통징계위원회 출석요구)

■ 공무원 징계령

## 별지

- [별지제2호서식] <개정 2023. 10. 10.>
- 출석통지서
- 인적사항 / 성명 / 구자훈 / 소속: 전북지원
- 인적사항 / 성명 / 구자훈 / 직위(직급): 운전주사보
- 인적사항 / 주소 전북특별자치도 전주시 완산구
- 출석 이유 / 징계위원회 출석 진술
- 출석 일시 / 2025년 8월 8일(금) 14시 00분
- 출석 장소 / 호텔 로제니아 2층 회의실(김천시 혁신3로 16)
- 유 의 사 항
- 1. 출석하여 진술하기를 원하지 않을 때에는 아래의 출석 진술 포기서를 즉시 제출하시기 바랍니다.
- 2. 사정이 있어 서면진술을 원할 때에는 징계위원회 개최일 전날까지 도착하도록 진술서를 제출하시기 바랍니다.
- 3. 정당한 사유서를 제출하지 않고 지정된 일시에 출석하지 않거나 서면진술서를 제출하지 않으면 진술할 의사가 없는 것으로 보아 처리합니다.
- 4. 성실하고 능동적인 업무처리 과정에서 과실로 인하여 징계의결등이 요구된 경우에는 징계위원회에서 징계감면을 받을 수 있으니, 이에 해당한다고 판단하는 경우 적극행정에 대한 증빙자료를 제출하시기 바랍니다.
- 「공무원 징계령」 제10조에 따라 위와 같이 귀하의 출석을 통지합니다.
- 2025년 7월 3일
- 국립농산물품질관리원보통징계위원장
- 구자훈 귀하
- 자 르 는 선
- 출석 진술 포기서
- 인적사항 / 성명 / 소속
- 인적사항 / 성명 / 직위(직급)
- 인적사항 / 주소
- 본인은 귀 징계위원회에 출석하여 진술하는 것을 포기합니다.
- 년 월 일
- 성명 (서명 또는 인) 국립농산물품질관리원보통징계위원회 귀중
