## 본문

◉국토교통부고시 제2023-45호

「과천지식정보타운역(가칭) 신설사업」 및 「신경주역 역명 개정」에 대하여 「철도사업법」 제 4조 및 같은 법 시행규칙 제2조 제2항, 「철도건설사업 시행지침」 제33조, 「철도 노선 및 역의 명 칭 관리지침」 제4조에 따라 사업용 철도노선과 철도거리표를 변경 고시합니다.

2023년 02월 06일 국토교통부장관

사업용 철도 노선 및 철도거리표 변경 고시

□ 사업용 철도 노선 변경 고시

ㅇ 과천선

1. 노선번호 : 317(변경없음)
2. 노 선 명 : 과천선(변경없음)
3. 기점(起點) : 경기도 군포시 금정동 688 일원(변경없음)
4. 종점(終點) : 서울특별시 서초구 방배동 2909 일원(변경없음)
5. 중요 경과지(정차역)

- 당초 : 경기도 군포시(금정역) … 경기도 과천시(정부과천청사역, 과천역, 대공원역, 경마공원 역, 선바위역), 서울특별시 서초구(남태령역)
- 변경 : 경기도 군포시(금정역) … 경기도 과천시(과천정보타운역, 정부과천청사역, 과천역, 대 공원역, 경마공원역, 선바위역), 서울특별시 서초구(남태령역)

ㅇ 경부고속선

1. 노선번호 : 101(변경없음)
2. 노 선 명 : 경부고속선(변경없음)
3. 기점(起點) : 경기도 광명시 뚝방길 117 일원(변경없음)
4. 종점(終點) : 부산광역시 동구 중앙대로 206 일원(변경없음)
5. 중요 경과지(정차역)

- 당초 : 경기도 광명시(광명역) … 경상북도 경주시(신경주역) … 부산광역시(부산역)
- 변경 : 경기도 광명시(광명역) … 경상북도 경주시(경주역) … 부산광역시(부산역)

ㅇ 동해선

1. 노선번호 : 311(변경없음)
2. 노 선 명 : 동해선(변경없음)
3. 기점(起點) : 부산광역시 동구 충장대로 255 일원(변경없음)
4. 종점(終點) : 경상북도 영덕군 영덕읍 우곡리 산 33-1 일원(변경없음)

5. 중요 경과지(정차역)

- 당초 : 부산광역시 동구(부산진역, 범일역) … 경상북도 경주시(신경주역, 서경주역, 안강역) … 경상북도 영덕군(장사역, 강구역, 영덕역)
- 변경 : 부산광역시 동구(부산진역, 범일역) … 경상북도 경주시(경주역, 서경주역, 안강역) … 경상북도 영덕군(장사역, 강구역, 영덕역)
