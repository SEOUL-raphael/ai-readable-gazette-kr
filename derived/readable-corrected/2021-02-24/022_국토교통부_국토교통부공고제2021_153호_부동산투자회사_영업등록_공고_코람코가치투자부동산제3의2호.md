## 본문

# 제19946호 가 보 2021. 2. 24.(수요일)

1. 상 호 : ㈜대한제29호파주금찌위탁관리부동산투자회사
2. 대표이사 : 이규석
3. 본윐 : 서울특별시 강남구 소동대로 517, 26층(삼성동)
4. 설립자본금 : 3억원
5. 설립목면적 : 경기도 파주시 금찌동 337-15번지 일원에 정비사업연계형 공공지원민간임대주택을 임 대운소 후 처분하는 사업
6. 소업인가일 : 2021년 1월 25일

◉국토교통부공고제2021-153호부동산투자회사 소업등록

*[원본 이미지 1]*

｢부동산투자회사법｣제9조의2에 따라 부동산투자회사 소업등록 사항에 대하여 아래와 같이 공고합 니다.

2021년 2월 24일 국토교통부장가

1. 상 호 : ㈜코람코가치투자부동산제3의2호위탁관리자부동산투자회사
2. 법인이사 : 주식회사 코람코자산신탁
3. 본윐 : 서울시 강남구 삼성로 511, 4층(삼성동, 골든타워)
4. 설립자본금 : 3억원
5. 설립목면적 : 경기도 수원시 소통구 하동 갑교 신도시에 소재 툐매시설(갤러리아백화윐 갑교윐)을 취 득하여 임대운소 후 처분
6. 소업등록일 : 2021년 1월 29일

◉국토교통부공고제2021-154호부동산투자회사 변경등록

*[원본 이미지 2]*

｢부동산투자회사법｣제40조에 따라 부동산투자회사 변경등록 사항에 대하여 아래와 같이 공고합니 다.

2021년 2월 24일 국토교통부장가

1. 상 호 : ㈜코람코가치투자부동산제3호위탁관리모부동산투자회사
2. 법인이사 : 주식회사 코람코자산신탁
3. 본윐 : 서울특별시 강남구 삼성로 511, 4층(삼성동, 골든타워)
4. 변경등록사항 : ㈜코람코가치투자부동산제3의2호위탁관리부동산투자회사*의 보통주를 매입하여 운 용

* 경기도 수원시 갑교 신도시 소재한 갤러리아백화윐을 취득하여 임대운소하는 투자회사

5. 변경등록일 : 2021년 1월 29일
