국가기술표준원장

1. 표준번호 및 표준명

※ 표준내용은 e-나라표준인증(www.standard.go.kr)에서 확인 가능

2. 제정 사유

ㅇ KS C IEC TS 62878-2-1 : 사회적 요청에 의한 표준화
ㅇ KS C IEC 62878-1-1 : 사회적 요청에 의한 표준화
ㅇ KS C IEC 62878-2-5 : 사회적 요청에 의한 표준화
ㅇ KS C IEC 61249-2-2 : 사회적 요청에 의한 표준화

3. 주요 제정 내용

구분 | 표준번호 | 표준명
---
제정|KS C IEC TS 62878-2-1|부품내장기판 ― 2-1부: 지침 ― 기술의 일반 설명
제정|KS C IEC 62878-1-1|부품내장기판 ― 제1-1부: 일반 규격 ― 시험 방법
제정|KS C IEC 62878-2-5|부품내장조립기술 ― 제2-5부: 지침 ― 부품내장 기판용 3D 데이터 형식 구현
제정|KS C IEC 61249-2-2|회로기판 및 다른 내부 접속용 구조를 위한 재료

제2-2부: 강화 원자재, 덮임 및 비덮임 페놀 수지를 적용한 셀룰로오스 종이 강화 시트, 고전기 등급, 동박 적층

ㅇ KS C IEC TS62878-2-1 : 전자회로기판의 제조 공정에서 능동 또는 수동 소자와 같은 개별 요소 및 시트 형성 요소를 포함하는 유기 기반 재료를 사용하여 제조된 부품내장기판에 대한 기술의 일반 설명
ㅇ KS C IEC 62878-1-1 : 수동 및 능동 부품내장기판의 시험방법에 대하여 규정
ㅇ KS C IEC 62878-2-5 : 부품내장기판에 대한 설계 데이터 형식을 나타내는 XML 스키마에 기초한 요구사항을 규정
ㅇ KS C IEC 61249-2-2 : 0.8 mm에서 3.2 mm 두께의 고 전기 등급의 페놀수지 기반 셀룰로 오스 종이 강화 동박 덮힘 적층 시트의 특성에 대한 요구사항
