## 본문

◉국방부고시 제2023-3호

사회기반시설에 대한 민간투자법 제15조에 의거『육군 3사관학교 교육시설 민간투자시설사업 (BTL)』실시계획을 다음과 같이 승인하였기에 고시합니다.

실시계획 승인 고시

2. 사업개요

◦ 사업위치 / 면적

- 위치 : 경상북도 영천시 고경면 등 필지 일원
- 면적 : 교육본청(행정시설)(5,795.72㎡) / 교육본청(복지시설)(2,942.01㎡) / 교육사열대(1,079.68㎡) / 교육지원시설(2,623.17㎡) / 교육생생활관(19,529.1㎡) / 통합교육관(3,690.36㎡) / 군악연주실(664.32㎡) / 안보교육시설(772.71㎡)

◦ 사업규모

- 행정동 1, 복지동 1, 생활관 1, 교육지원시설 1, 통합교육관 1, 군악연주실 1, 안보교육시설 1, 교육사열대 2

◦ 시행기간 : 공사 착수일로부터 737일 이내

3. 사업시행자 : 영천수호(주)
4. 사업 주무관청과 그 주소

◦ 주무관청 : 국 방 부
