## 본문

◉국토교통부공고 제2021-474호

한국산업표준을 개정함에 있어 국민, 업계 및 관련기관에 미리 알려 의견을 듣고자 개정 사유와 주요 개정 내용을 「산업표준화법」 제5조제1항 및 같은 법 시행령 제16조에 의하여 다음과 같이 고시합니다.

2021년 4월 09일 국토교통부장관

한국산업표준 개정 예고

1. 표준번호 및 표준명

구분 | 표준번호 | 표준명
---
개정|KS X ISO 19107:2019|지리정보 — 공간 스키마
개정|KS X ISO 19116:2019|지리정보 — 측위 서비스
개정|KS X ISO 19136-1:2020|지리정보 — 지리 마크업 언어(GML)

— 제1부: 기본사항
개정|KS X ISO/TS 19139-1:2019|지리정보 — XML 스키마 구현 — 제 1부: 인코딩 규칙
개정|KS X ISO 19150-2:2015|지리정보 — 온톨로지 — 제2부:웹 온톨로지 언어(OWL)를 이용한 온톨로지 개발 규칙

※ 표준(안) 내용은 e-나라표준인증(www.standard.go.kr)에서 확인 가능

2. 개정 사유

ㅇ KS X ISO 19107:2019 : 국제표준 개정 내용 반영
ㅇ KS X ISO 19116:2019 : 국제표준 개정 내용 반영
ㅇ KS X ISO 19136-1:2020 : 국제표준 개정 내용 반영
ㅇ KS X ISO/TS 19139-1:2019 : 국제표준 개정 내용 반영
ㅇ KS X ISO 19150-2:2015 : 국제표준 개정 내용 반영

3. 주요 개정 내용ㅇ KS X ISO 19107:2019 : 지리적 개체의 공간 특성을 기술하기 위한 개념 스키마 및 해당 스키

마와 일관된 공간 연산의 집합을 규정

ㅇ KS X ISO 19116:2019 : 위치를 제공하는 장치와 위치를 사용하는 장치 사이의 통신을 가능하 게 하는 인터페이스 내용 및 데이터 구조 정의
ㅇ KS X ISO 19136-1:2020 : 공간정보 분야 국제/국가표준에서 사용되는 개념적 모델링 프레임 워크를 준수하여 모델링된 공간정보를 전송하고 저장하기 위한 XML 인코딩 정의
ㅇ KS X ISO/TS 19139-1:2019 : 지리 자원을 명시하는 UML 패키지의 집합을 포함하는 개념적 스키마를 위한 XML 기반의 인코딩 규칙을 제공
ㅇ KS X ISO 19150-2:2015 : 온톨로지 작성 언어인 웹 온톨로지 언어(OWL)를 이용하여 시맨틱 웹에서 공간정보의 상호운용성을 더 잘 지원할 수 있도록 온톨로지 개발에 관한 규칙과 가이 드라인 정의

4. 의견 제출 이 개정(안)에 대한 의견이 있는 개인, 업체 또는 관련 기관은 2021년 6월 1일까지 다음사항을 기재한 의견서를 국토교통부장관(공간정보진흥과)에게 제출하여 주시기 바랍니다.

ㅇ 기타 자세한 내용은 국토교통부 공간정보진흥과 안종태 사무관 (세종특별자치시 도움6로 11(6 동), 전화: 044-201-3471, e-mail: jtan1969@korea.kr)로 문의하여 주시기 바랍니다.
