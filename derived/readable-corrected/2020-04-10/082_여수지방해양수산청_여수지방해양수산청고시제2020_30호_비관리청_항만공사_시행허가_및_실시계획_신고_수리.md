# 제19729호 관 보 2020. 4. 10.(금요일)

◉여수지방해양수산청고시제2020-30호 비관리청 항만공사 시행허가 및 실시계획 신고 수리 고시

「항만법」 제9조제8항의 규정에 의하여 다음과 같이 비관리청 항만공사 시행허가 및 실시계획 신고 수리하였기에 이를 고시합니다.

2020년 4월 10일 여수지방해양수산청장

1. 항만명 : 광양항
2. 공사의 명칭 : 사포2부두 LG화학 납사 이송․하역시설 등 설치공사
3. 공사 장소 : 여수시 낙포동 160-6 / 1275 / 1289번지
4. 공사개요 : 이송배관(30ʺ×583 m / 2ʺ×44 m / 24ʺ×3 m / 6ʺ×18 m / 4ʺ×7 m / 3ʺ×16 m / 2ʺ×12 m / 1.1/2ʺ×2 m / 1ʺ×3 m / 3/4ʺ×13 m), 로딩암(이동식) 2기, 드레인 드럼 1기, Box Culvert(3.7 m×8.1 m), 부대공 1식 등
5. 공사기간 : 착공일로부터 7개월
6. 공사에 필요한 총사업비 : 금4,503,700,000원(비귀속)
7. 공사시행자 성명 : ㈜LG화학 대표이사 신학철 주소 : 서울특별시 영등포구 여의대로 128(여의도동). 끝.

◉여수지방해양수산청고시제2020-31호 비관리청 항만공사 시행허가 및 실시계획 변경 신고 수리 고시

2020년 4월 10일 여수지방해양수산청장

1. 항만명 : 광양항
2. 공사의 명칭 : 광양항 동측배후단지 대평 창고 증축공사
3. 공사 장소 : 광양시 도이동 825번지
4. 공사개요(변경)

- (변경 전) 창고 6동(3,832.85 m2 / 3,782.85 m2 / 3,620.31 m2 / 4,939.5 m2 / 2,269.55 m2 / 570.8 m2)
- (변경 후) 창고 6동(3,832.85 m2 / 3,782.85 m2 / 3,620.31 m2 / 4,939.5 m2 / 1,894.55 m2 / 540 m2)

5. 공사기간 : 착공일로부터 7개월
6. 공사에 필요한 총사업비 : 금4,950,000,000원(비귀속)

- 성명 : ㈜대평 대표이사 고재천
- 주소 : 전남 광양시 항만7로 54(도이동). 끝.
