## 본문

◉국립전파연구원고시 제2023-09호

「산업표준화법」제5조에 따라 산업표준심의회 심의를 거쳐 정보통신분야 국가표준을 제정하고, 같은 법 제11조 및 같은 법 시행령 제23조,「정보통신표준 개발·운영 세칙」 제5조에 따라 정보통신분야 국가표준을 다음과 같이 고시합니다.

2023년 04월 21일 국립전파연구원장

정보통신 국가표준 제정

1. 표준번호 및 표준명
2. 제정 사유

- 사물 인터넷 활용 및 시스템 구현, 증강 현실 등 IoT 기반 서비스 활성화를 위해 국제표준을 부합화하여 마련

3. 주요 내용

- (KS X ISO/IEC 23093-1) 미디어 사물 인터넷을 위한 시스템의 아키텍처와 활용사례를 기술
- (KS X ISO/IEC 23093-2) 네트워크 내 다른 미디어 사물의 검색과 미디어 사물 간 통신을 위한 기본 API를 포함하는 추상 클래스를 규정
- (KS X ISO/IEC 23093-3) 미디어 사물 사이에서 교환되는 데이터 포맷과 미디어 사물 사이 에서 이러한 데이터를 교환하는 API를 규정
- (KS X ISO/IEC 19785-3) 서로 다른 기관에서 개발한 생체인식 기반 응용 프로그램과 시스템의 상호 운용성 확보하기 위한 패트론 포맷을 규정
- (KS X ISO/IEC 9995-9) 다양한 국가나 문화권에서 사용되는 문자와 기호를 입력하기 위한 키보드 문자 위치 규정

연번 | 표준번호 | 표준명
---
1|KS X ISO/IEC 23093-1|정보 기술 — 미디어 사물 인터넷 — 제1부: 아키텍처
2|KS X ISO/IEC 23093-2|정보 기술 미디어 사물 인터넷 제2부: 검색 및 통신 API
3|KS X ISO/IEC 23093-3|정보 기술 — 미디어 사물 인터넷 — 제3부: 미디어 데이터 형식 및 API
4|KS X ISO/IEC 19785-3|정보 기술 — 일반 생체인식 교환 포맷 프레임 워크 — 제3부: 패트론 포맷 명세
5|KS X ISO/IEC 9995-9|정보 기술 — 사무 시스템을 위한 키보드 배열 — 제9부: 다국어 다 문자 키보드 배열
6|KS X ISO/IEC 30113-60|정보 기술 — 제스처 기반 인터페이스 — 제60부: 스크린리더용 제스처의 일반 지침
7|KS X ISO/IEC 18038|정보 기술 — 컴퓨터 그래픽스, 영상 처리 및 환경 표현 — 혼합/증강 현실에서 센서 표현
8|KS X ISO/IEC 18040|정보 기술 — 컴퓨터 그래픽스, 영상 처리 및 환경 데이터 표현 — 혼 합/증강 현실에서 라이브 행위자와 실체 표현

- (KS X ISO/IEC 30113-60) 다양한 ICT 장치에서 실행되는 스크린리더에서 사용자가 제스처를 쉽게 사용할 수 있도록 일반 지침을 제공
- (KS X ISO/IEC 18038) 디지털 가상공간에 현실 세계의 상태 정보를 전달하기 위한 물리적 센서의 프레임워크와 참조모델 정의
- (KS X ISO/IEC 18040) 혼합/증강 현실에 라이브 행위자와 실체(LAE)를 표현하고 제어하기 위한 참조모델, 기본 구성요소를 정의한 표준
