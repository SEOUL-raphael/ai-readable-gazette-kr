# 경기도남부경찰청공고제2021-3호(경비업체 허가취소 청문통지 공시송달)

## 본문

◉경기도남부경찰청공고 제2021-3호

2021년 5월 20일 경기남부경찰청장

경비업체 허가취소 청문통지 공시송달 경비업법에 의거 해당 경비업체에 대하여 행정처분(허가취소)하고자 청문통지하니 청문기일에 출 석하여 의견을 진술하여 주시기 바라며, 청문기일까지 의견진술이 없는 경우에는 의견이 없는 것 으로 보아 경비업 허가취소 함을 알려 드립니다.

1. 청문일시 및 장소 : ’21. 5. 31. 16:00, 경기남부지방경찰청 생활안전계
2. 당사자

가. 대상업체 : 엔에스시티디펜스(주) (대표 : 변재술)
나. 허가업무 : 시설경비, 신변보호
다. 허가번호 : 경기남부지방경찰청장 제2027호(2018. 9. 20.)
라. 소 재 지 : 경기도 이천시 마장면 이장로 107-10

3. 처분의 원인된 사실 : 최초 허가일(2018. 9. 20.)의 다음 날부터 2년 이내에 경비 도급실적이 없 음
4. 처분하고자 하는 내용 : 시설경비, 신변보호 허가취소
5. 법적근거 : 경비업법 제19조 제1항 5호 (경비업 허가의 취소 등)
6. 문의처 : 경기남부지방경찰청 생활안전과 경사 엄명호(☎ 031-888-3846)
