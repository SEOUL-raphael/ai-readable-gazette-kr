## 본문

◉기획재정부령 제897호

증권거래세법 시행규칙 일부개정령을(를) 다음과 같이 공포한다. 2022년 03월 18일 부총리 겸 기획재정부장관

증권거래세법 시행규칙 일부개정령 증권거래세법 시행규칙 일부를 다음과 같이 개정한다. 별지 제1호의4서식을 별지와 같이 한다.

## 부칙

부 칙
제1조(시행일) 이 규칙은 2022년 7월 1일부터 시행한다.
제2조(서식에 관한 경과조치) 이 규칙 시행 전에 증권시장에서 주권등의 매매거래가 체결된 경우에는 별 지 제1호의4서식의 개정규정에도 불구하고 종전의 서식에 따른다.

(앞쪽)

## 별지

- [별지제1호의4서식]
- 비과세양도명세서
- (금융투자업자용)
- □ 문서번호: 년 월 일
- □ 수신: 한국예탁결제원
- □ 발신: 금융투자업자 대표자 (서 명 또 는 인 )
- □ 제목: 비과세양도명세서
- ｢증권거래세법 시행령｣ 제6조에 따라 주권의 비과세양도명세서를 제출하오니 거래징수 대상 에서 제외하여 주시기 바랍니다.
- ❶ 매매 / ❷ 양도자 / ⑥ 주권의 종목명 / ⑦ 주식 수 / ⑧ 매매 금액 / ⑨ 비과세 근거 / ⑩ 양도자 구분 / ⑪ 비고
- ①년 / ②월 / ③일 / ④성명 (법인명) / ⑤계좌 번호 / ⑥ 주권의 종목명 / ⑦ 주식 수 / ⑧ 매매 금액 / ⑨ 비과세 근거 / ⑩ 양도자 구분 / ⑪ 비고
- 210mm×297mm[백상지 80g/㎡(재활용품)]
- (뒤쪽)
- 작성방법
- 1. ❶ 매매의 ① ∼ ③란은 연, 월, 일의 두자리씩 적습니다.
- 2. ④ 성명란에는 양도자의 성명 또는 법인명을 적습니다.
- 3. ⑤ 계좌번호란에는 양도자의 계좌번호를 적습니다.
- 4. ⑥ ∼ ⑧란에는 양도한 주권의 종목명, 주식 수, 매매금액을 적습니다.
- 5. ⑨ 비과세근거란에는 「조세특례제한법」제117조에 따른 비과세 근거 조항을 적습니다.
- 6. ⑩ 양도자 구분란에는 양도자 구분에 따라 다음의 분류코드를 적습니다.
- 구분 / 금융투자업자 / 보험회사 / 사모집합투자기구 / 기타집합투자기구 / 은행
- 분류 코드 / 1000 / 2000 / 3100 / 3000 / 4000
- 구분 / 기타 금융기관 / 연금, 기금 및공제회 / 국가, 지방자치단체, 국제기구및공익기관 / 기타법인 / 개인
- 분류 코드 / 5000 / 6000 / 7000 / 7100 / 8000
- ◇ 개정이유 및 주요내용
- 정거래소가 주권 등의 매매 관련 사항을 전자등록기관에 통지하는 경우 주권의 종목 명, 수량 외 에 투자자를 분류할 수 있는 정보를 추가하도록 하는 내용으로 「증권거래세법」 및 같은 법 시행령 이 개정됨에 따라 관련 서식을 정비하려는 것임.
