# 제19696호 가 보 2020. 2. 25.(화요일)

◉인천광역시공고제2020-450호

「환경관리 대행기가의 지정 등에 관한 규칙」 제4조제5항 규정에 따라 다음과 같이 환경관리 대행 기가 등록말소(자진반납) 사항을 공고합니다.

2020년 2월 25일 인천광역시장

환경관리 대행기가 등록말소

1) 업 체 명 : 그린환경화학
2) 대 표 자 : 송재민
3) 소업소재지 : 인천광역시 남동구 남동대로 242(논프동, 3층)
4) 환경관리 대행기가의 종류 : 대기환경관리 대행기가
5) 지 정 번 호 : 대기 제 8호
6) 지 정 일 자 : 2005. 6. 10.
7) 취 소 사 유 : 자진반납
8) 취 소 일 자 : 2020. 2. 18.

◉광주광역시공고제2020-379호

환경위문공사업 소재지 변경등록

환경기술 및 환경산업 지원법 시행규칙 제32조 규정에 의해 다음과 같이 환경위문공사업 소재지가 변경되었음을 공고합니다.

2020년 2월 25일 광주광역시장

1. 상 호 : 청호환경개발(주)
2. 대 표 자 : 임 형 엽
3. 소 재 지 : 광주광역시 북구 청계로 48, 2층(용밉동) (변경위 : 전라남도 장성군 삼서면 소장로 1930-52)
4. 소업분야 : 수질 환경위문공사업
5. 등록번호 : 제20호
6. 등 록 일 : 2020. 2. 19.

◉강원도원주교육지원청공고제2020-14호

공유재산 무단윐유에 따른 변상금 사위통지 공시송달

「강원도교육비특별회계 소가 공유재산 관리조례」제59조에 의거하여 강원도교육감 소유의 공유재 산의 무단윐유자에게 변상금 사위통지서를 수차례 발송하씀으나 폐문부재로 반송되어 송달이 불가능 하므로 행정윈차법 제14조 4항에 따라 다음과 같이 공시송달 공고합니다.

2020년 2월 25일 강원도원주교육지원청 교육장

1. 제목: 공유재산 변상금 사위통지 공고
