사업용 철도노선 및 철도거리표 변경 고시

□ 사업용 철도노선 변경 고시

○ 서해선(홍성~송산) 복선전철 건설사업

1. 노선번호 : 202 (변경없음)
2. 노 선 명 : 서해선(홍성~송산) (변경없음)
3. 기점(起點)

- 당초 : 충청남도 홍성군 홍성읍 고암리 일원
- 변경 : 충청남도 홍성군 홍성읍 조양로 272 일원

4. 종점(終點) : 경기도 화성시 남양읍 문호리 일원 (변경없음)
5. 중요 경과지(정차역)

- 당초 : 충청남도 홍성군(홍성역), 충청남도 예산군(장래신설역), 충청남도 당진시(101정거장), 충청남도 아산시(102정거장), 경기도 평택시(103정거장), 경기도 화성시(104, 105, 106정거장)
- 변경 : 충청남도 홍성군(홍성역), 충청남도 예산군(장래신설역), 충청남도 당진시(합덕역), 충 청남도 아산시(인주역), 경기도 평택시(안중역), 경기도 화성시(향남역, 화성시청역, 서 화성역)

○ 이천∼문경 철도건설사업

1. 노선번호 : 204 (변경없음)
2. 노 선 명 :

- 당초 : 중부내륙선(이천∼충주)
- 변경 : 중부내륙선

3. 기점(起點) :

- 당초 : 경기도 이천시 부발읍 일원(부발역)
- 변경 : 경기도 이천시 부발읍 신아로 87 일원(부발역)

4. 종점(終點)

- 당초 : 충청북도 충주시 봉방동 일원(충주역)
- 변경 : 경상북도 문경시 마성면 외어리 712-38 일원

5. 중요 경과지(정차역)

- 당초 : 경기도 이천시(경강선 부발역), 경기도 여주시(가남역), 경기도 이천시 및 충청북도 음 성군(감곡장호원역), 충청북도 충주시(앙성온천역, 충북선 충주역)
- 변경 : 경기도 이천시(경강선 부발역), 경기도 여주시(가남역), 경기도 이천시 및 충청북도 음 성군(감곡장호원역), 충청북도 충주시(앙성온천역, 충북선 충주역, 살미역, 수안보온천 역), 충청북도 괴산군(연풍역), 경상북도 문경시(문경역)

○ 동해선 포항∼삼척 철도건설사업

1. 노선번호 : 311 (변경없음)
2. 노 선 명 : 동해선 (변경없음)
3. 기점(起點) : 부산광역시 동구 충장대로 255 일원 (변경없음)
4. 종점(終點)

- 당초 : 경상북도 영덕군 영덕읍 우곡리 산 33-1 일원
- 변경 : 강원도 삼척시 사직동 51-16 일원

5. 중요 경과지(정차역)

- 당초 : 부산광역시 동구(부산진역, 범일역), 부산광역시 부산진구(부전역), 부산광역시 연제구 (거제해맞이역, 거제역, 교대역), 부산광역시 동래구(동래역, 안락역, 부산원동역), 부산 광역시 해운대구(재송역, 센텀역, 벡스코역, 신해운대역, 송정역), 부산광역시 기장군(오 시리아역, 기장역, 일광역, 좌천역, 월내역), 울산광역시 울주군(서생역, 남창역, 망양역, 덕하역), 울산광역시 남구(개운포역, 태화강역), 울산광역시 북구(북울산역), 경상북도 경주시(경주역, 서경주역, 안강역) 경상북도 포항시(포항역, 월포역), 경상북도 영덕군 (장사역, 강구역, 영덕역)
- 변경 : 부산광역시 동구(부산진역, 범일역), 부산광역시 부산진구(부전역), 부산광역시 연제구 (거제해맞이역, 거제역, 교대역), 부산광역시 동래구(동래역, 안락역, 부산원동역), 부산 광역시 해운대구(재송역, 센텀역, 벡스코역, 신해운대역, 송정역), 부산광역시 기장군(오 시리아역, 기장역, 일광역, 좌천역, 월내역), 울산광역시 울주군(서생역, 남창역, 망양역, 덕하역), 울산광역시 남구(개운포역, 태화강역), 울산광역시 북구(북울산역), 경상북도 경주시(경주역, 서경주역, 안강역) 경상북도 포항시(포항역, 월포역), 경상북도 영덕군 (장사역, 강구역, 영덕역, 영해역, 고래불역), 경상북도 울진군(후포역, 평해역, 기성역, 매화역, 울진역, 죽변역, 흥부역), 강원도 삼척시(옥원역, 임원역, 근덕역, 삼척역)

○ 수도권광역급행철도 A노선 민간투자사업

1. 노선번호 : 327 (변경없음)
