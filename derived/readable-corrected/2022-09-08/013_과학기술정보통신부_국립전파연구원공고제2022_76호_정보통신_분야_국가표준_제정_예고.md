## 본문

◉국립전파연구원공고 제2022-76호

정보통신 분야 국가표준을 제정하면서 국민, 업계 및 관련 기관에 미리 알려 의견을 듣고자 제정 사유와 주요 내용을 「산업표준화법」 제5조, 같은 법 시행령 제16조 및 「정보통신표준 개발·운영 세칙」 제2조 제3항에 따라 다음과 같이 예고합니다.

2022년 09월 08일 국립전파연구원장

정보통신 분야 국가표준 제정 예고

1. 표준번호 및 표준명
2. 제정 사유

① KS X ISO/IEC 23093-1 국제표준 부합화에 따른 표준화
② KS X ISO/IEC 23093-2 국제표준 부합화에 따른 표준화
③ KS X ISO/IEC 23093-3 국제표준 부합화에 따른 표준화

3. 주요 내용

① KS X ISO/IEC 23093-1 정보 기술 ― 미디어 사물 인터넷 ― 제1부: 아키텍처

o 미디어 사물 인터넷을 위한 시스템의 아키텍처와 활용사례를 제시하는 표준

② KS X ISO/IEC 23093-2 정보 기술 ― 미디어 사물 인터넷 ― 제2부: 검색 및 통신 API

o 네트워크 내 다른 미디어 사물의 검색과 미디어 사물과의 통신을 위한 기본 API를 포함하는 미디어 사물의 추상 클래스를 규정하는 표준

③ KS X ISO/IEC 23093-3 정보 기술 ― 미디어 사물 인터넷 ― 제3부: 미디어 데이터 형식 및 API

2|멀티미디어 부호화|KS X ISO/IEC 23093-2|정보 기술 미디어 사물 인터넷 제2부: 검색 및 통신 API
3|멀티미디어 부호화|KS X ISO/IEC 23093-3|정보 기술 미디어 사물 인터넷 제3부: 미디어 데이터 형식 및 API

o 미디어 사물 사이에서 교환되는 데이터를 포맷과 미디어 사물 사이에서 이러한 데이터를 교환하는 API를 규정하는 표준
