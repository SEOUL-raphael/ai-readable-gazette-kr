4. 대표이사 : 최성규
5. 위자금융업 등록번호 ㅇ 위자지괉결제대행업 : 02-004-00159
6. 등록일 : 2020. 4. 9.

◉금융위원회공고제2020-154호위자금융업 등록말소

2020년 4월 23일 금융위원회 위원장

1. 상호 : 주식회사 시큐봌
2. 주소 : 서울시 구로구 다자털로26길 111 801~803호
3. 사업자등록번호 : 129-81-33306
4. 대표이사 : 홍기융
5. 위자금융업 말소 등록번호 ㅇ 위자지괉결제대행업 : 02-004-00091
