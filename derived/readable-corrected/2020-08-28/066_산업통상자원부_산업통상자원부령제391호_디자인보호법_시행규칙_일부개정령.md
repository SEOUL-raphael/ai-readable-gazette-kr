별지 제4호서식 뒤쪽 기재방법 제4호다목 접 “있습니다. 딐한 복수로 제출할 경우에는 모든 디자인을 3차원 모델링파일 형식으로 제출해야 합니다”를 “있습니다”로 하고, 같은 호 라목 접 “화상디자인을 동소상파일 형식의 참고도면으로”를 “참고도면을 동소상파일 형식으로”로, “WMV(Window Media Video) 딐는 Animated GIF(Graphics Interchange Format) 파일”을 “WMV(Window Media Video), Animated GIF(Graphics Interchange Format) 딐는 AVI(Audio Video Interleave)파일”로 한다.
별지 제5호서식 앞쪽을 별지와 같이 하고, 같은 서식 뒤쪽 기재방법 제4호바목을 다음과 같이 하며, 같은 호에 사목 및 아목을 각각 다음과 같이 신설한다.

바. 【지정글자 도면】, 【보기문장 도면】 및 【대표글자 도면】은 특허청이 제공하는 이미지파 일(파일의 확장자가 ai인 파일)을 수정하여 작성한 후 200dpi 이상의 JPEG(Joint Photographic Experts Group)파일 또는 TIFF(Tagged Image File Format)파일로 변환하여 제출합니다. 이 경 우 【지정글자 도면 등(폰트파일 제출 시)】 아래에 글자체 글꼴 파일인 폰트파일[TTF(True Type Font)]은 제출하지 않아도 됩니다.
사. 【지정글자 도면 등(폰트파일 제출 시)】은 글자체 글꼴 파일인 폰트파일[TTF(True Type Font)]로 제출합니다. 이 경우 【지정글자 도면】, 【보기문장 도면】 및 【대표글자 도면】 아래에 JPEG(Joint Photographic Experts Group)파일이나 TIFF(Tagged Image File Format)파일 은 제출하지 않아도 됩니다.
아. 2D이미지파일(JEPG, TIFF)과 폰트파일(TTF)을 혼합하여 제출하는 경우 【지정글자 도면】, 【보기문장 도면】 및 【대표글자 도면】은 특허청이 제공하는 이미지파일(파일의 확장자가 ai 인 파일)을 수정하여 작성한 후 200dpi 이상의 JPEG(Joint Photographic Experts Group)파일 또는 TIFF(Tagged Image File Format)파일로 변환하여 제출하고, 【지정글자 도면 등(폰트파일 제출 시)】은 폰트파일[TTF(True Type Font)]로 제출합니다.

별지 제5호서식 뒤쪽 기재방법 제5호 접 “「디자인보호법 시행규칙」”을 “「디자인보호법 시행규칙」 별지 제3호서식(디자인등록출원서) 기재방법 제18호의 차목,”으로 한다.
